## About The Project

[![Product Name Screen Shot][product-screenshot]](https://your-demo-link.com)

Municipal Comparator is a data-driven web application designed to compare Brazilian municipalities using structured socioeconomic indicators.  

The platform transforms complex public datasets into clear, interactive visualizations that allow side-by-side comparison of cities based on income distribution, occupational structure, and demographic metrics.

The project focuses on frontend architecture, scalability, and structured data modeling, applying best practices in componentization, API integration, and performance optimization.

Core features include:

- Side-by-side municipality comparison
- Income average and median analysis
- Household per capita income
- Salary distribution by income brackets
- Wages by occupation
- Dynamic data visualization
- Responsive UI optimized for desktop and mobile

## Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

* Node.js (v18+ recommended)
* npm

```sh
npm install npm@latest -g
````

### Installation

1. Clone the repository

```sh
git clone https://github.com/github_username/municipal-comparator.git
```

2. Navigate to the project folder

```sh
cd municipal-comparator
```

3. Install dependencies

```sh
npm install
```

4. Run the development server

```sh
npm run dev
```

5. Open in browser

```
http://localhost:3000
```

## Usage

The application allows users to:

* Search and select multiple municipalities
* Compare income metrics side-by-side
* Analyze economic stratification through salary class distribution
* Evaluate occupational wage differences
* Explore structured indicators for purchasing power and socioeconomic positioning

The system is designed with feature-based architecture and scalable folder organization, enabling easy expansion for new indicators or datasets.
