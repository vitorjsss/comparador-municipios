# Municipal Comparator

Data-driven web application for comparing Brazilian municipalities using structured socioeconomic and income indicators.

This project demonstrates scalable frontend architecture, structured data modeling, and performance-aware UI engineering.

---

## Project Overview

Public socioeconomic datasets are complex and difficult to interpret.

Municipal Comparator transforms raw structured data into clear, side-by-side analytical comparisons, enabling better understanding of:

* Income distribution
* Occupational wage structure
* Economic positioning
* Socioeconomic indicators

---

## Key Features

### Municipality Comparison

* Side-by-side comparison of multiple municipalities
* Structured indicator visualization

### Income Metrics

* Average income
* Median income
* Household per capita income

### Economic Structure

* Income distribution by salary brackets
* Occupational wage breakdown
* Comparative economic positioning

### User Experience

* Fully responsive interface
* Clear visual hierarchy
* Dynamic data rendering

## Local Development

### Requirements

* Node.js (v18 or higher recommended)
* npm

### Installation

Clone the repository:

git clone [https://github.com/vitorjsss/comparador-municipios.git](https://github.com/vitorjsss/comparador-municipios.git)

Enter the folder:

cd comparador-municipios

Install dependencies:

npm install

Run development server:

npm run dev

Open in browser:

[http://localhost:3000](http://localhost:3000)
